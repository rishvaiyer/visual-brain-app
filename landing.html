Visual Brain · est. 2026

Thirty-five seconds, no sound.

Browse a page, hover an image, click Save. Open the board. That is the whole product.

What it does

Clip from anywhere

Hover any image in Chrome or Edge and a small Save button appears. It lands on your board at the best resolution the page has.

Infinite boards

Boards inside folders. Text, frames, shapes and sketches next to your images. Pan, zoom, drag, crop.

Finds things

Search titles, tags and collections. On a Mac it also reads what is in the picture, so untagged images still turn up.

Yours, entirely

One folder: a SQLite file and your originals. No account. No cloud. Export everything as a ZIP any time.

Run it in two minutes

  1. Download the latest release and unzip it, or git clone the repository.
  2. Start it. Mac: double-click Open Visual Brain.command. Anywhere else:
    python3 -m pip install -r requirements.txt
python3 server.py
  3. Add the extension. Open chrome://extensions, turn on Developer mode, Load unpacked, choose the extension folder. Paste the pairing key from the board's Extension setup.

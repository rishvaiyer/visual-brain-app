What it does

Everything you pin, none of the feed.

Clip from anywhere

Hover any image in Chrome or Edge and a small Save button appears. It lands on your board at the best size the page has.

Boards with no grid to fight

Drop pictures anywhere. Tilt them, crop them, add notes, frames and sketches. Folders keep the boards tidy.

Finds things for you

Search titles, tags and collections. On a Mac it also reads what is in each picture, so untagged ones still turn up.

Yours, entirely

One folder: a database file and your originals. No account, no cloud. Export everything as a ZIP any time.

Run it

Two minutes, start to finish.

  1. Download the latest release and unzip it, or git clone the repository.
  2. Start it. On a Mac, double-click Open Visual Brain.command. Anywhere else:
    python3 -m pip install -r requirements.txt
python3 server.py
  3. Add the extension. Open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the extension folder. Paste the pairing key from the board's Extension setup.

Start a board in under a minute.

Open the playground to feel how it works, then keep your own private copy.

Visual Brain

A visual board that lives on your own computer.

Save any image from the web with one click. Arrange it on infinite boards. Search it by title, tag, or what is in the picture. Nothing leaves your machine.

Try the live demo Download Source on GitHub

The demo is a shared public playground. Anything you add is visible to everyone and is wiped every few hours. Your own install is private.

Clip from anywhere

Right-click or hover any image in Chrome or Edge and it lands on your board at full resolution.

Infinite canvas

Boards and folders. Text, frames, shapes, drawings. Pan, zoom, drag, resize.

Search that works

Titles, tags, and collections. On Apple Silicon, search by what the picture shows.

Yours

One SQLite file and a folder of originals. Export everything as a ZIP any time.

Run it yourself

  1. Download the latest release and unzip it, or git clone the repository.
  2. In that folder run:
    python3 -m pip install -r requirements.txt
python3 server.py
  3. Open http://127.0.0.1:8777. Mac users can double-click Open Visual Brain.command instead.
  4. Load the extension folder in chrome://extensions (Developer mode, Load unpacked) and paste the pairing key from the board's Extension setup.
